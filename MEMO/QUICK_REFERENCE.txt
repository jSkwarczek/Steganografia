KLUCZOWE KLASY
═══════════════════════════════════════════════════════════════════════

1. ConvolutionalEncoder()
   ├─ encode(bits: List[int]) → List[int]
   │  └─ Input: 0/1 bity → Output: bity×2 + flush
   └─ Parametry: G1=0o171, G2=0o133, K=7

2. ViterbiDecoder()
   ├─ decode(received_bits: List[int]) → List[int]
   │  └─ Input: potencjalnie błędne bity → Output: naprawione bity
   └─ Stany: 64 (2^6), Metryka: Hamminga

3. CBOCModulator()
   ├─ modulate(bits, carrier_text: str) → str
   │  └─ Input: bity → Output: tekst ze zmianami
   ├─ demodulate(stego_text: str) → List[int]
   │  └─ Input: tekst zmieniony → Output: bity
   └─ Metody: homoglify + zero-width markery

4. GalileoSteganography()
   ├─ hide_message(secret, carrier_text) → str
   ├─ extract_message(stego_text) → str
   ├─ _text_to_bits(text) → List[int]
   └─ _bits_to_text(bits) → str

ROZMIARY DANYCH
═══════════════════════════════════════════════════════════════════════

N znaków wiadomości:

  Oryginalnie:        N × 8 bitów
  Po kodowaniu:       (N × 8 + 6) × 2 ≈ N × 16 bitów
  Słów potrzeba:      N × 8 + 6 słów

Carrier minimum:      ~8 słów na 1 znak wiadomości

═══════════════════════════════════════════════════════════════════════
ALGORYTM KROK PO KROKU
═══════════════════════════════════════════════════════════════════════

UKRYWANIE (hide_message):
  1. secret → 8 bitów/znak
  2. enkoder: bity → rate-1/2 kod (× 2) + flush
  3. modulator: bity → homoglify + ZW znaki w słowach carrier
  4. wynik: stego_text (wysyłamy publicznie!)

WYDOBYWANIE (extract_message):
  1. stego_text → czytamy homoglify + ZW znaki
  2. dekoder Viterbi: (możliwie błędne) bity → naprawione bity
  3. traceback: usuwamy K-1 flush bitów
  4. bity → 8 bitów/znak
  5. wynik: recovered secret


═══════════════════════════════════════════════════════════════════════
TYPOWE PROBLEMY I ROZWIĄZANIA
═══════════════════════════════════════════════════════════════════════

PROBLEM: ZW znaki usunięte
  PRZYCZYNA: Edytor / kanał normalizuje Unicode
  OBJAWY: bit2 zawsze 0
  ROZWIĄZANIE: Viterbi potrafi naprawić jeśli <4 błędy

PROBLEM: Homoglify zmienione na łacinkę
  PRZYCZYNA: Odbiorca konwertuje cyrylicę do łaciny
  OBJAWY: bit1 zawsze 0
  ROZWIĄZANIE: Duplikuj bit1 w wielu słowach

PROBLEM: Słowo bez pasujących liter
  PRZYCZYNA: Słowo "123" nie ma żadnej litery
  OBJAWY: bit1=1 nie może być ustawiony (milcząco ignorowane!)
  ROZWIĄZANIE: Zgłoś błąd i fallback na inne słowo

PROBLEM: Carrier za krótki
  PRZYCZYNA: Mniej słów niż (N×8+6)
  OBJAWY: ValueError przy hide_message()
  ROZWIĄZANIE: Zwiększ carrier lub skróć wiadomość

PROBLEM: Niezgodne kodowanie (UTF-8 vs ASCII)
  PRZYCZYNA: Znaki >127 są obcinane
  OBJAWY: Unicode znaki znikają
  ROZWIĄZANIE: Zakoduj UTF-8 zamiast ord()


═══════════════════════════════════════════════════════════════════════
WALIDACJA DANYCH
═══════════════════════════════════════════════════════════════════════

✓ secret_message:
  - Typ: str (ASCII lub Unicode)
  - Min długość: 1 znak
  - Max długość: brak teoretycznego limitu (praktycznie: carrier size / 8)

✓ carrier_text:
  - Typ: str (normalny tekst)
  - Min słów: 8 × len(secret) + 6
  - Musi zawierać min. homoglify dla bit1=1

✓ received_bits (po demodulacji):
  - Typ: List[int] (0/1)
  - Parzysta długość (automatycznie wyrównywana)
  - Może zawierać błędy (Viterbi je naprawia)

import unittest
from test3 import GalileoSteganography

class TestGalileoSteganography(unittest.TestCase):
    
    def setUp(self):
        self.stego = GalileoSteganography()
        self.carrier = "word " * 100  # 100 słów
    
    def test_short_message(self):
        secret = "A"
        stego_text = self.stego.hide_message(secret, self.carrier)
        recovered = self.stego.extract_message(stego_text)
        self.assertEqual(recovered.strip(), secret)
    
    def test_medium_message(self):
        secret = "prezes"
        stego_text = self.stego.hide_message(secret, self.carrier)
        recovered = self.stego.extract_message(stego_text)
        self.assertEqual(recovered.strip(), secret)
    
    def test_carrier_too_short(self):
        secret = "test"
        short_carrier = "word1 word2"  # za mało
        with self.assertRaises(ValueError):
            self.stego.hide_message(secret, short_carrier)
    
    def test_round_trip(self):
        for secret in ["A", "test", "hello"]:
            stego_text = self.stego.hide_message(secret, self.carrier)
            recovered = self.stego.extract_message(stego_text)
            self.assertEqual(recovered.strip(), secret)

if __name__ == '__main__':
    unittest.main()

COMMON PITFALLS
═══════════════════════════════════════════════════════════════════════

❌ Używanie Unicode (np. "hello 🎉")
   → bity będą >8 bitów/znak, tracenie danych
   ✅ Rozwiązanie: UTF-8 encoding lub ASCII-only

❌ Carrier bez wystarczającej redundancji liter
   → bit1 nie może być ustawiony na 1
   ✅ Rozwiązanie: wybierz carrier bogatszy w słowa

❌ Edytowanie stego_text po wygenerowaniu
   → Usunięcie ZW znaków lub zmiana cyrylicy
   ✅ Rozwiązanie: traktuj stego_text jako binary data

❌ Brak weryfikacji carrier length przed hide_message()
   ✅ Rozwiązanie: zawsze sprawdzaj len(carrier.split())

❌ Ignor ValueError przy niewystarczającym carrier
   ✅ Rozwiązanie: dodaj try/except albo validerror handler


═══════════════════════════════════════════════════════════════════════
ZŁOŻONOŚĆ — PODSUMOWANIE
═══════════════════════════════════════════════════════════════════════

┌──────────────────┬─────────────────┬──────────────────┐
│ Operacja         │ Czas            │ Pamięć           │
├──────────────────┼─────────────────┼──────────────────┤
│ Encoder          │ O(n)            │ O(1)             │
│ Modulator        │ O(m)            │ O(m)             │
│ Demodulator      │ O(m)            │ O(m)             │
│ Viterbi Decoder  │ O(t × 64 × 2)   │ O(t² × 64)       │
│ End-to-end       │ O(m + t²)       │ O(m + t²)        │
└──────────────────┴─────────────────┴──────────────────┘

Gdzie:
  n = liczba bitów oryginalnych
  m = liczba słów w carrier
  t = liczba symboli (received_bits / 2)
  64 = liczba stanów Viterbi
