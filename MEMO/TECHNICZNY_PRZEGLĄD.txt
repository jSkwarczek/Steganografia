PARAMETRY ENKODERA KONWOLUCYJNEGO
═════════════════════════════════════════════════════════════════════════════════

Standard:            Galileo I/NAV (GPS-like)
Generator 1:         G1 = 0o171 = 001 111 001 (binarnie)
Generator 2:         G2 = 0o133 = 001 011 011 (binarnie)
Constraint Length:   K = 7 (rejestr 6-bitowy + 1 wejście)
Kod Rate:            1/2 (1→2 bity)
Liczba stanów:       2^(K-1) = 64

Flush bits:          K-1 = 6 (dodawane na koniec)
Zdolność korekty:    ~3-4 błędy bitów w oknie


PARAMETRY MODULACJI CBOC
═════════════════════════════════════════════════════════════════════════════════

Bitów na słowo:      2 (bit1 + bit2)
Metoda bit1:         Homoglify (cyrylica)
Metoda bit2:         Zero-width markery

Homoglify (łacina → cyrylica):
  a→а, e→е, o→о, p→р, c→с, y→у, x→х, i→і, j→ј, s→ѕ
  A→А, E→Е, O→О, P→Р, C→С, Y→У, X→Х, I→І, J→Ј, S→Ѕ

Zero-width znaki:
  bit=1: U+200B (Zero Width Space)
  bit=0: U+200C (Zero Width Non-Joiner)


WYMIARY DANYCH
═════════════════════════════════════════════════════════════════════════════════

Wiadomość:      N znaków

Krok 1 - Text to Bits:
  Bitów:        8N

Krok 2 - Kodowanie konwolucyjne:
  Bitów + flush: (8N + 6) = 8N + 6
  Kodowanych:   (8N + 6) × 2 = 16N + 12

Krok 3 - Modulacja CBOC:
  Słów potrzeba: ⌈(16N + 12) / 2⌉ ≈ 8N + 6

Wymóg: carrier_text musi mieć ≥ 8N + 6 słów

Przykład:
  N = 6 ("prezes"):
    - Bitów oryginalnych:    48
    - Bitów po kodowaniu:    108
    - Słów potrzeba:         54
    - Carrier minimum:       54 słowa


ALGORYTM VITERBI — PSEUDO-KOD
═════════════════════════════════════════════════════════════════════════════════

# Inicjalizacja
metrics[0..63] = [0, ∞, ∞, ..., ∞]        # Stan 0 ma metrykę 0
paths[0..63]   = [[], [], ..., []]        # Puste ścieżki

# Forward pass
FOR t = 0 TO num_symbols-1 DO
    received_symbol = (bit0, bit1)
    
    FOR from_state = 0 TO 63 DO
        IF metrics[from_state] = ∞ THEN CONTINUE
        
        FOR input_bit IN {0, 1} DO
            next_state = transition_function(from_state, input_bit)
            expected = encoder_output(from_state, input_bit)
            
            distance = hamming(received_symbol, expected)
            new_metric = metrics[from_state] + distance
            
            IF new_metric < metrics[next_state] THEN
                metrics[next_state] = new_metric
                paths[next_state] = paths[from_state] + [input_bit]
            END IF
        END FOR
    END FOR
END FOR

# Traceback
best_state = argmin(metrics)
best_path = paths[best_state]
best_path = best_path[:-K+1]  # Usuń flush bits

RETURN best_path


ZŁOŻONOŚĆ
═════════════════════════════════════════════════════════════════════════════════

Enkoder Konwolucyjny:
  Czas:     O(N) dla N bitów
  Pamięć:   O(1) (tylko stan)

Modulator CBOC:
  Czas:     O(M) dla M słów
  Pamięć:   O(M)

Dekoder Viterbi:
  Czas:     O(T × S × 2) gdzie T=liczba symboli, S=64 stanów
            ≈ O(T × 128)
  Pamięć:   O(T × S × L) gdzie L=średnia długość ścieżki
            ≈ O(T × 64 × T) = O(T²) [nieoptymalne!]

  Dla T=54 symboli:
    - Czas: ~54 × 128 = 6912 operacji (błyskawiczny)
    - Pamięć: ~54 × 64 × 54 = 186K liczb (20 MB dla float64)


POTENCJALNE BŁĘDY TRANSMISJI
═════════════════════════════════════════════════════════════════════════════════

1. ZERO-WIDTH ZNAKI USUNIĘTE
   Problem: Edytor / kanał sieciowy usuwa U+200B/U+200C
   Skutek:  bit2 zawsze = 0 (brak markera)
   Rozwiązanie: Viterbi korekcja błędów

2. HOMOGLIFY ZIGNOROWANE
   Problem: Odbiornik widzi tekst i zmienia cyrylicę na łacinkę
   Skutek:  bit1 zawsze = 0
   Rozwiązanie: Duplikowanie bitów lub interleaving

3. SŁOWA BEZ HOMOGLIFÓW
   Problem: Słowo "why" nie zawiera żadnej litery do zamiany
   Skutek:  bit1=1 nie może być ustawiony
   Realizacja: Kod milczący ignoruje (BUG!)

4. ZMIANA CARRIER_TEXT
   Problem: Tekst nośny jest edytowany/skracany
   Skutek:  Niektóre słowa znikają z danymi bitów
   Rozwiązanie: Błędna wiadomość lub wyjątek


PRZYCHODNI — POPRAW JAKIE BITY
═════════════════════════════════════════════════════════════════════════════════

Metryka Hamminga dla symbolu (2 bity):
  received = (r0, r1)
  expected = (e0, e1)
  distance = (r0 ⊕ e0) + (r1 ⊕ e1)
  
  Możliwe wartości: 0, 1, 2
  - 0: perfect match
  - 1: 1 bit error (Viterbi potrafi naprawić)
  - 2: both bits wrong (Viterbi próbuje minimalnej sumy)

Zdolność Viterbi: ~3-4 błędy w ciągu 54 symboli (108 bitów)
