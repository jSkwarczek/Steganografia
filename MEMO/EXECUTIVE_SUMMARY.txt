STRESZCZENIE WYKONAWCZE
═══════════════════════════════════════════════════════════════════════════════

System Galileo-CBOC Viterbi to zaawansowany algorytm steganograficzny (ukrywania
informacji), który pozwala na bezpieczne przesłanie tajnej wiadomości poprzez
zwykły, publicznie dostępny tekst. Osoba trzecia obserwująca komunikację nie
będzie w stanie zauważyć, że wiadomość w ogóle istnieje.

Algorytm łączy trzy nowoczesne techniki:
  1. Kodowanie konwolucyjne (z korekctą błędów)
  2. Modulacja CBOC (ukrywanie w tekście)
  3. Dekodowanie Viterbi (odczyt z możliwym szumem)

PRZEGLĄD BIZNESOWY

CO TO ROBI?

  System ukrywa tajną wiadomość w zwykłym tekście nośnym. Nadawca wysyła
  pozornie niezinny dokument, ale zawiera on zakodowaną informację, którą
  tylko autoryzowany odbiorca może wydobyć.

  Przykład:
    Wiadomość:  "prezes"
    Carrier:    "Lorem ipsum dolor sit amet consectetur adipiscing..."
    Wynik:      "Lorem i‌psum d‌olor sit а‌met ..." (z ukrytymi znakamí)
    
  Wysłane publicznie - osoba trzecia nie będzie widzieć "prezes"!


PRZYPADKI UŻYCIA

  1. Bezpieczna komunikacja korporacyjna
     → Wysyłanie wrażliwych informacji przez publiczne kanały
     
  2. Tajne transfery danych
     → Przesyłanie instrukcji bez ryzyka wykrycia
     
  3. Watermarking dokumentów
     → Zagnieżdżanie znacznika autentyczności w tekście
     
  4. Badania nad bezpieczeństwem
     → Testowanie odporności systemów na stego-ataki
     
  5. Ochrona praw autorskich

ANALIZA RYZYKA
───────────────────────────────────────────────────────────────────────────────

RYZYKA TECHNICZNE

  ⚠️  HIGH: Zero-width znaki mogą być usunięte
      Mitigacja: Viterbi potrafi naprawić do ~4 błędy
      Plan B: Duplikuj bity w wielu słowach
      
  ⚠️  MEDIUM: Homoglify mogą być zauważone
      Mitigacja: Użyj homoglifów bardzo podobnych
      Plan B: Przemieszaj bity w całym tekście
      
  ⚠️  LOW: Carrier za krótki
      Mitigacja: Validacja przed hide_message()
      Plan B: Kompresja wiadomości


RYZYKA BEZPIECZEŃSTWA

  🔓 MEDIUM: Brak szyfrowania
      → Informacja ukryta, ale nie zaszyfrowana
      Mitigacja: Dodaj AES-256 zanim zostanie zakodowana
      
  🔓 LOW: Steganografia może być wykryta
      → Przy podejrzeniu, attacker może szukać homoglifów
      Mitigacja: Kombinerowanie z kryptografią


RYZYKA BIZNESOWE

  📉 MEDIUM: Regulacja (ITAR, export control)
      → Steganografia może być objęta restrykcjami
      Mitigacja: Konsultacja z legal/compliance
      
  📉 LOW: Patenty stron trzecich
      → Viterbi jest public domain, homoglify są znane
      Mitigacja: Prior art analysis + konsultacja

API I INTEGRACJA (dla programistów)

NAJPROSTSZE UŻYCIE

  from test3 import GalileoSteganography
  
  stego = GalileoSteganography()
  
  # Ukrywanie
  stego_text = stego.hide_message("secret", "carrier text...")
  
  # Wydobywanie
  secret = stego.extract_message(stego_text)


INTEGRACJA Z ISTNIEJĄCYMI SYSTEMAMI

  1. Komunikacja
     API: hide_message(msg, carrier) → encrypted_carrier
          ↓ wysłanie HTTP/SMTP/etc.
          extract_message(carrier) → msg
     
  2. Baza danych
     API: store(encrypt(hide_message(...)))
          load(...) → extract_message(decrypt(...))
     
  3. Dokumenty
     API: hide_message(watermark, document_text) → watermarked_doc
          extract_message(received_doc) → watermark


INTERFEJSY DOSTĘPNE

  Public Methods:
    • hide_message(secret: str, carrier: str) → str
    • extract_message(stego_text: str) → str
    
  Utility Methods:
    • _text_to_bits(text: str) → List[int]
    • _bits_to_text(bits: List[int]) → str
    
  Class Methods:
    • ConvolutionalEncoder.encode(bits) → bits
    • ViterbiDecoder.decode(bits) → bits
    • CBOCModulator.modulate(bits, carrier) → text
    • CBOCModulator.demodulate(text) → bits
